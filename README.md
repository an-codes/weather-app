# ☁️ Should I Leave the House?

A tiny weather app that answers one important question:

“Is it worth leaving the house today?”

Instead of just showing the weather, the app calculates a Leave-the-House Score (0–100) based on real weather data.

Sometimes it's a perfect main-character walk day.
Sometimes it's Netflix weather.

## 🌤️ Features

- Search weather by city

- Or use your current location

- Real-time weather data from the OpenWeather API

- A Leave-the-House Score (0–100)

- Fun randomized verdicts like:

  - ☕ Coffee run approved

  - 📸 Main character moment possible

  - 🚫 Absolutely not. Stay inside.

- Cute animated background weather icons

- Lightweight single-file app

## 🧠 How the score works

The app calculates a score based on:

- 🌡 Temperature

- 💨 Wind speed

- ☁️ Cloudiness / rain

- 📅 Weekend bonus

Higher score = better excuse to go outside.

Example:

Score	Verdict
0–29	Stay inside
30–59	Coffee run only
60–79	Walk maybe
80–100	Go outside immediately
